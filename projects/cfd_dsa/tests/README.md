# 回归测试

统一运行，不需要逐个找脚本：

```bash
python3 -B -m unittest discover -s projects/cfd_dsa/tests
```

| 目录 | 检查范围 |
|---|---|
| `arithmetic/` | FP64除法器、RF端口、lane、广播、树归约 |
| `memory/` | SPM、Tile、预取、队列与缓存容量 |
| `numerics/` | 输入文件、独立oracle、CPU基线和数据条件化 |
| `contracts/` | 单线约束、私有LU、取消/恢复和参考隔离 |
| `reporting/` | 验收、配置审计、完整轨迹及计时口径 |
| `maintenance/` | 历史归档恢复、校验与拒绝危险路径 |
| `research/` | 独立算法原型，尚非gem5时序实现 |
| `fixtures/` | 原生C/C++硬件模型和oracle测试源文件 |

`_support.py`统一设置项目路径；各模块不再复制`sys.path`初始化。
整理时的235项测试完整保留；加上独立到达、回读顺序及原生选择器检查为247项；增加12项D输入独立就绪和16项冷轮R供给、分批初始化、挂起额度及物理读取检查为275项；新增13项算术分组记分牌、分批归属、注册返回、借用及反例重放检查，共288项。
运行一个模块可用`python3 -B -m unittest discover -s projects/cfd_dsa/tests -p test_lane_mvm.py`。
增加LU倒数复用、有限drain描述符、资源容量及带时序摘要的原生模型和反例重放后为302项。摘要覆盖两周期字段返回、所有权、取消排空及冷轮限定策略。

新增6项双五分量发射、本地bank端口、32标签容量、所有权/传递延迟、错误本地读取及容量守恒检查，当前共308项。

新增9项有界快照、双引擎、五周期复制、在途/复制中取消、元数据容量与局部FU额度释放反例检查后共317项。

新增4项局部乘积/全局部分和的放置、非法写回、最终减法和容量守恒检查，并扩展原生 MVM 节点到操作数槽的映射测试，当前共321项。

新增13项第一轮诊断检查：同请求/同三角步配对、base RHS 保护口径、有限发射资源、标称与实际返回、局部注册传递、DMA/SPM 身份关联、物理 MVM 绑定及排空反例；当前共334项。

第二轮公共因子配对测试补充后为342项。本轮新增8项LU双槽、跨周期因子保持、实际返回和反例重放检查，当前为350项。证据同一性比较器另有4项反例自测，位于本轮结果包，不计入项目350项。
