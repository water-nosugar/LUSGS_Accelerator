# 5/5/1 与 10/10/1：按整轮周期选择的两个优化配置（2026-10-27）

目标改为最小化完整一次 LU-SGS sweep 的执行周期；利用率用于解释瓶颈，不参与配置筛选。两种算术数量分别独立选择已测最快组合。下面的“最佳”限于当前冻结版本、这份 1024 点冷轮输入和已经通过完整验收的候选。

|配置|加速器整轮周期|CPU 观察到完成/周期|周期/点|2 GHz 模型下整轮时间/μs|
|---|---|---|---|---|
|5 MUL / 5 ADD-SUB / 1 DIV|136042|139054|132.854|68.0210|
|10 MUL / 10 ADD-SUB / 1 DIV|129331|132342|126.300|64.6655|

10/10/1 相对各自调优后的 5/5/1 节省 6711 周期，整轮耗时降低 **4.933%**，加速比 **1.0519×**。CPU 观察到完成的时间节省 6712 周期，降低 4.827%，确认收益延续到软件等待完成的计时。该计时不代表整个 CFD 程序或非线性收敛时间。

两者还共同保留：13 点计算窗口、8 个输入槽、16 点/Tile、前向双 Tile、4 个后向 Tile 预取缓冲、按 cell/列流式消费、输出合并、真实 RF 返回反压，以及单实例 12 周期延迟、II=4 的除法器。FP64 MUL/ADD 延迟为 3/4 周期。`legacy` 是原直接共享发射路径的名称，所有阶段仍共享算术池。

5/5/1 的精简组合加上完成快照后更快：较早的同算法对照 137150 周期降为 136042，节省 1108 周期。两种资源配置适合的优化组合不同，不能只改变乘加器数量后就称为各自最优。上表内所有开关按整组实测选择，尚未逐项证明每一项单独造成的收益。

完成快照和双整数摘要引擎具有有界深度、五周期字段复制及带时序的哈希处理；它们计入容量。10/10/1 的局部 LU/RHS 乘积通路同样支付标签、端口、存储和注册传递。上表预约容量不是综合门面积，额外乘加器、RF/路由和整数单元仍需独立评估面积、功耗与频率。

10/10/1 组合启用了 LU/RHS 倒数共享，减少除法并增加乘法，两组的浮点操作数目因此不同。它们求解同一输入，均通过同一个 200 位 Decimal、带主元选择的独立参考检查和原数值容差；舍入顺序可能不同。最佳组合之间的收益包含算法与数据通路选择，不能全部归因于增加乘加器。

## 4. 推荐范围

针对本次 1024 点冷轮，以最少周期为目标时选 best10101-1024；需要保留 5/5/1 算术数量时选 best551-1024。两套都保留单通道 DDR4、RF16R/8W、4 个 SPM bank 和 256 KiB 保守统一预算。该结论是固定输入、有限候选的实测选择，尚非跨独立数据的通用最优。

4096 点已有当前版本的 10/10/1 结果：广播关闭 640480 周期、开启 640834 周期，因此该长线保留广播关闭。当前没有与这两组 5/5/1 最佳候选同条件的 4096 点复核，不能给出对应长线加速比。65 点一冷两热也有独立短线参数点，完整系数缓存和长期热轮收益必须另外判断。尚未实现按线长/冷热条件自动切换。
