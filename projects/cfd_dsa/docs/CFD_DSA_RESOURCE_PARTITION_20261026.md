# 单线算术资源共享、固定分组与借用实验

四种资源组织已经实现为实验开关。默认 `legacy` 保留旧执行路径；实验结果以同二进制完整对照为准，
不能将资源数量、理想下界或减少某项等待直接当作加速效果。

本页方案均使用 `--coeff-compute-model=shared`。`--coeff-arithmetic-mode=legacy`
指原有共享发射路径，与旧的非共享 compute-model 参数含义不同。

## 模式与参数

|组织|参数|资源|
|---|---|---|
|旧共享基线|`--coeff-arithmetic-mode=legacy`|默认 5 MUL / 5 ADD / 1 DIV|
|同机制 5/5/1 控制|`--coeff-arithmetic-mode=shared`|5/5/1，有界分批发射机制|
|全共享扩充|`--coeff-arithmetic-mode=shared --coeff-cluster-mul-count=8 --coeff-cluster-add-count=7`|8/7/1|
|固定分组|`--coeff-arithmetic-mode=fixed --coeff-cluster-mul-count=8 --coeff-cluster-add-count=7`|预处理 5/5/1；扫描 3/2/0|
|扫描优先、允许借用|`--coeff-arithmetic-mode=borrow --coeff-cluster-mul-count=8 --coeff-cluster-add-count=7`|相同 8/7/1，允许使用另一组的空闲通道|

另支持总 7/8/1，对照增加 2 MUL＋3 ADD。固定/借用模式要求 MUL、ADD 均超过五通道。
旧路径仍只支持既有的 5/5/1 或新增一个 MUL，保留原 LU-only 选项；新模式不与 LU-only、逐行局部 RF、
预处理广播或专用最终减法器混合，避免隐藏重复资源和未校验的通路组合。

共同实验参数：

|参数|缺省|含义|
|---|---:|---|
|`--coeff-arithmetic-depth`|12|逻辑操作记分牌条目，范围 4～32|
|`--coeff-arithmetic-width`|4|每周期最大新操作接收数，以及最大物理分批发射组数|
|`--coeff-arithmetic-select`|1|从逻辑操作接收到可选择发射的注册周期，范围 1～8|
|`--coeff-arithmetic-route`|1|全部 RF 结果返回后的汇合/发布周期，范围 0～8|
|`--coeff-arithmetic-borrow-route`|1|使用另一归属组通道后的额外结果路由周期，范围 0～8|
|`--coeff-arithmetic-age`|32|借用模式的等待补偿阈值，范围 1～256|

这些延迟是可审计的硬件假设，尚未经目标 RTL 或布局布线标定。旧基线与统一机制控制组都保留，
用以区分新增时序/控制代价和新增算术的收益。`route=0` 仅作路由敏感性，不等同于免费物理连线。

## 数据和执行契约

1. 原 LU/RHS/列乘与反馈状态机提交一个宽度 1～5 的操作。操作源由已经准备好的请求/列操作数状态保持稳定；
   接收成功后原状态机进入等待，不允许重复提交同一步。
2. 记分牌同时最多持有 depth 个操作，给扫描消费者保留两个条目；每周期最多接收 width 个。
3. 注册选择到期后，可将一个五通道操作拆成若干物理分批。每批明确记录逻辑 offset、宽度、物理 lane mask、RF tag。
4. 每批使用真实算术资源和现有 RF 端口，支付原 MUL/ADD 延迟，并受有限返回额度、RF 写回仲裁和反压约束。
   不同分批若分别读取同一个广播因子，会分别计入读取，不能免费复用。
5. 各批结果返回后置有效位；所有分量返回并经过 route，才发布原操作的完成回调。
   部分结果不被原整体向量消费者提前使用。FP64 乘加顺序保持原状态机定义。
6. 借用只作用于尚未发射的分批。已发射批次保留归属标签，正常返回；请求取消后仍须排空其已接受操作，
   原请求/版本检查阻止失效结果进入后续数值状态。取消和事件队列的静止判定计入所有记分牌条目。

现有算术 RF 与返回额度为集中共享结构。固定分组限制算术通道归属，并不隐含两组独立 RF 或新的端口。
DIV 继续使用原有单实例流水除法器、在途额度和结果 FIFO，不经过此乘加记分牌。

## 仲裁与物理归属

- shared：就绪操作按接收顺序选择，可以使用池内全部空闲通道。
- fixed：预处理只使用编号 0～4；扫描只使用新增通道。两类仍共享 RF 和注册接收机制。
- borrow：未达到 age 的就绪操作优先扫描；达到 age 的操作按接收顺序优先，防止生产者长期饥饿。
  扫描先取新增通道，再借原有通道；预处理先取原有通道，再使用空闲新增通道。
  任何跨归属通道的操作在结果发布时支付一次额外 borrow-route。

新模式均支持分批发射，固定 3 MUL/2 ADD 不会再因为整组申请五通道而永久阻塞。
每周期发射额度、归属、物理 lane 冲突、RF 读取和返回时序均有独立检查器重放。

主对照采用 depth=12，另测 depth=32 与 width=8。容量不能只按队列条数经验设置：
条目从接收到全部返回发布一直占用，两项扫描预约使12项配置的预处理占用最多十项。
应以每类操作数×最低驻留时间估算必要容量，再测量反压、存储边界和选择时序；
大记分牌会减少同一统一预算下可用于系数缓存的空间，不能免费扩大。

## 容量与验证

每个记分牌条目保守预约 256 B，覆盖标签、稳定操作数所有权、结果有效位和路由等待状态。
新增算术通道另计 operand/pipeline/result 预约，沿用每通道按 128 B 对齐的保守模型。
预约同时进入控制器、配置入口、存储验收和有效参数审计；不能将此预算作为综合面积。

`CFD_ARITH_GROUP` 记录接收、每个物理分批和最终发布。`CFD_ARITHMETIC_SUMMARY` 报告容量、峰值和排空计数。
issue事件中的 `crossed` 是该逻辑组截至当前的累计跨组标志；当前批的物理归属应按 lane mask 解释。
独立重放将每个非除法 RF 操作绑定到且仅绑定到一个逻辑操作，核对分量覆盖和注册路由。
原物理 RF/算术完整检查仍先执行；树归约和依赖检查消费经过全部物理返回证明的逻辑视图。
资源发射率和运行时统计始终使用真实物理分批，避免把逻辑接收当作算术发射。

取消恢复、有限 SPM、DMA、Tile、版本、原有数值容差和独立 Decimal 参考保持验收范围。
