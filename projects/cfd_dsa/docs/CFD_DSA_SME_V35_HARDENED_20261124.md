## 4. 核心定量结论与硬件现实评估

1. **硬件现实化约束（`hw8 + fbr1` vs `unlim + fbr0`）的真实代价已清晰量化**：
   * **暖轮**：引入点间反馈寄存 1 拍（`fbr1`）后，`T1` 暖轮精确增加 **`+8,187` 拍（+5.86%，`139,767 → 147,954`）**，`T2` 暖轮增加 **`+8,187 ~ +8,608` 拍（+3.99% ~ +4.19%）**，精确贴合 $2 \times 4095 = 8190$ 拍的单线前后扫递推下界增量（`T1` 变为 19 拍/点，`T2` 变为 27 拍/点）。
   * **冷轮**：有限 8 候选窗口 + 反馈打拍使 `T1` 冷轮增加 **`+2,478 ~ +4,827` 拍（+1.23% ~ +2.42%）**，`T2` 冷轮增加 **`+3,431 ~ +4,510` 拍（+1.46% ~ +1.87%）**。这证明 8 候选窗口基本保留了 2D 行分段打包的大部分吞吐，但先前的理想模型确实低估了 ~1.5%–2.4% 冷轮与 ~4%–5.9% 暖轮周期。

2. **P0 与 P1 在 `T1` 和 `T2` 上表现出截然不同的主导机制**：
   * **`T1`（短延迟 ASIC）以 P1 为主，P0 几乎无增量收益**：
     * 单独开 **P1（6 槽轮转）** 将冷轮降低 **−1.50%（`hw8+fbr1`） / −2.43%（`unlim+fbr0`）**，且每轮稳定减少 **4 块 Tile（5,120 B、84 个 DMA 包）** 的后向重读，不增加 SPM 占用。
     * 单独开 **P0（Panel B 提前装填）** 在 `T1 hw8+fbr1` 下反而微升 **+582 拍（+0.29%）**（因短延迟下提前装填与就绪发射争抢 8 候选窗口与行槽，`pack_stall_row` 增 `+5,482`）；叠加 P1 后 `P0+P1` 仅比单 P1 多省 **159 拍（0.08%）**。考虑到 `T1` 2 GHz 对频率极其敏感（约 1.5% 频率损失即可抵消收益），**`T1` 方案下建议只保留流量收益确定的 P1，不强推 P0**。
   * **`T2`（长延迟 FPGA）以 P0 为主，且 P0+P1 产生显著正协同**：
     * 单独开 **P0** 直接将冷轮降低 **−3.58%（`−8,850` 拍，`hw8+fbr1`） / −3.48%（`−8,465` 拍，`unlim+fbr0`）**，有效掩盖了 `T2` 下 `DIV=18 / FMA=8` 的长流水线气泡；
     * 单独开 **P1** 仅省 −0.14% / −0.43%，但与 P0 组合后，P1 消除了前向 Tile 边界准入停顿，使 Panel B 提前重叠点数从 `3,760` 升至 `4,046`，把冷轮总降幅进一步扩大到 **−5.34%（`−13,190` 拍，`hw8+fbr1`） / −5.62%（`−13,668` 拍，`unlim+fbr0`）**，Guest ROI 同步下降 **−5.26% / −5.77%**。
   * **暖轮**：所有组合在同硬件约束下均无实质性暖轮收益（受单线递推反馈墙严格锁定；`T1` 暖轮整轮有效 PE 利用率在 `hw8+fbr1` 下为 **5.41%**，`T2` 为 **3.75%**）。

3. **当前证据边界与后续工作建议**：
   * **输入多样性边界**：16 组 4096 点主消融仍基于同一条强对角占优合成输入（全 4096 点零求逆回退）；虽然 `verify/` 已补充 65 点真实求解器线（`real-gt01r-s835-n65`）与病态回退线（`illcond65-guarded-hw`），但后续定型仍需引入更长规模的真实 CFD 算例与无预读（cold-DRAM）对照。
   * **物理后端时序与端口布线边界**：暖轮每轮存在 `86,000` 次旁路读与 `86,000` 次旁路写、`90,095` 次 ZA 读写，且 3.25 MiB SPM 仅余 `53,272 B`；已有 RTL 综合仅覆盖 RS 选择器与单返回槽子模块，完整 ZA 读写交叉开关、旁路总线与候选前端的布局布线 Fmax 仍需实测确认。
   * **架构演进重点（阶段 3）**：V35 的 `fbr1` 实验再次从硬件层面证实，单线模式下 64-PE 阵列的暖轮利用率天花板仅 **3.75%–5.41%**；下一阶段最核心的吞吐突破口应转向 **多线交错 / 块稀疏异步数据流前端**，以多条独立前沿填满流水线与 2D 阵列。
