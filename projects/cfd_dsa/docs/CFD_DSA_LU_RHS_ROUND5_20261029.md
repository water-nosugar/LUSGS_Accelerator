# 第五轮：LU 控制折叠与 RHS 提前供给（2026-10-29）

本轮在 gem5 模型中实现有界 LU 控制折叠，并与已有冷轮 RHS 提前预取组合。两个 1024 单元输入的整轮耗时分别降低 **0.5087% 和 0.2652%**；训练输入单点 LU 核心平均区间缩短 **13.1765%**。4096 单元候选只节省 25 周期，基本持平，推荐继续保留原 4096 配方。

新增 `--coeff-lu-control-fold=1`，全局默认仍为 0。1024 候选同时启用已有的 `--coeff-cold-rhs-prefetch=1`，其余参数沿用第四轮对应配方。

## 实现和资源约束

LU 原状态机在算术真实返回后，还逐拍执行寄存器提交、列索引推进和下一列操作数选择。新路径只合并这些控制转换，每个上下文每次访问最多折叠 3 次；原有每周期访问门控保留。PivotCheck、算术发射和等待状态均结束本次访问。

```mermaid
flowchart LR
  A[StoreUpper：结果实际返回后提交] --> B[NextColumn：推进列号]
  B --> C[StartLower：选择下一列输入]
  C --> D[下一列 MUL：仍支付原 FU 和 RF 额度]
```

这一段最多在同一次访问中完成 3 次控制转换。MUL3、ADD/SUB4、DIV12/II4、局部写入后的一拍发布及所有实际 RF 返回条件沿用原模型；不加入 FMA，不改变原有 k 顺序或浮点结合次序。

冷轮 RHS 预取利用已有有限输入队列，让 b 的 40 B 输入提前到达，使求解能与尚未结束的 LU/其余系数加载重叠。保持已有 RHS frontier 仲裁，不等待凑齐 RHS，不增设 RF 端口或 FU。

独立重放将每点 23 次控制折叠和 8 次算术结果提交绑定到真实 RF id、owner、generation、宽度及实际返回周期；首列继续受既有 D 输入就绪门控。检查器还约束每次访问最多 3 次折叠、最多 4 个 LU 上下文、取消后禁止继续折叠及最终排空。


| 资源配方 | 原预算 / B | 候选预算 / B | 候选余量 / B |
|---|---|---|---|
| 1024 组合配方 | 260800 | 261056 | 1088 |
| 4096 因子保持配方 | 260160 | 260416 | 1728 |

新增模型控制预留为 `32×LU上下文数+128 B`，LU4 为 **256 B**；配置分配、C++ 分配、storage/audit 和 RF 摘要均独立核对。保持 10 MUL / 10 ADD / 1 DIV、RF16R/8W、4 个 SPM bank、单 DDR 通道和 256 KiB 总预算。预留包含返回身份与控制选择，是模型预算，未进行 RTL 综合或时序签核。

## 消融与未采用的实验


| 同一最终二进制的 1024 对照 | 训练周期 | 独立周期 |
|---|---|---|
| 第四轮基线 | 128373 | 127445 |
| 只启用 LU 控制折叠 | 127057 | 127628 |
| LU 折叠 + RHS 提前预取（采用） | 127720 | 127107 |

最终选择采用两个输入均改善的组合。只看训练输入会偏向更快的单独折叠方案，但它在独立输入上退化；折叠后再把 LU 供给移到当前 RHS 之后的筛选结果为 126959 / 127490，也未采用。后者仅完成仿真筛选，未宣称独立完整验收。

此前 16 个原配置调度/归约筛选没有同时改善两个输入；前向首列直接落累加器的独立原型同样未通过共同收益标准，已从当前实现撤回。RHS 因子缓存的窄行过滤也已撤回：阈值 3 将训练 RF 读取从 901956 增到 916512 字，同时独立整轮退化。各原型具有独立源码/二进制快照和原始轨迹，不能与最终二进制的对照混作一次消融。

RF 复用继续使用第四轮两个有限因子槽；关键路径改进落实在实际返回后的 LU 控制推进及 RHS 输入提前供给。Tile24 与短线完整缓存分别保留对应已有配方。
