# 长线供数、回读与输出优化（2026-10-23）

本阶段以有效发射利用率、算术执行区间并集、控制器总周期三种指标共同评价优化。输入和运算次数受独立验收约束，不能通过额外运算、修改统计区间或隐藏数据搬运提高利用率。

运行记录和逐项对照报告位于 [完整实验报告](../../../../results/cfd_dsa/analysis/longline-opt-20261023/REPORT.md)，可复现参数见 [推荐 suite](../../suites/history/single-line-longline-recommended.json)。默认配置保留旧路径，各项改动可以独立关闭。

## 本阶段结果

4096 点冷轮采用相同输入、4 个 bank、192 KiB 设备预算与 5 MUL / 5 ADD / 1 DIV（II=4），正式对照保持一致性 DMA cache 的 tag/data/response 延迟各 50 周期。

| 配置 | 控制器周期 | 较基线减少 | 簇活跃率 | MUL / ADD / DIV 有效发射率 |
| --- | ---: | ---: | ---: | --- |
| 原资源基线 | 750024 | — | 89.63% | 38.77% / 33.31% / 32.77% |
| 预留2项＋y/Ubar流式回读 | 726133 | 3.19% | 92.49% | 40.04% / 34.40% / 33.85% |
| 推荐配置 | 526918 | 29.75% | 98.99% | 55.18% / 47.41% / 46.64% |
| 可选扩大配置 | 520255 | 30.63% | 98.93% | 55.89% / 48.02% / 47.24% |

推荐配置的主要新增资源是一致性 DMA 端点的 64 个 MSHR、32 个写回缓冲，以及 64 个 DMA 名额、64 项片上访问队列和18个最终输出槽。端点缓存仍为 1 KiB，LU/RHS 上下文保持4/4，设备预算峰值162560 B。可选扩大配置使用16 KiB端点缓存、8/8上下文及60项RHS乘积缓冲，峰值190336 B；相对推荐配置只再减少约1.26%的周期，应单独评估其成本。

推荐配置把后向总周期从165879降到94516、后向无算术执行周期从75674降到4418，输出队列满等待从27820降到588周期。后向MUL与ADD有效发射率仍仅约21.66%，DIV没有工作；单条网格线的递推依赖仍限制各通道填充。簇活跃超过95%不代表各单元有效发射达到95%，后者本阶段尚未达到。

GT01R真实连通256点路径的推荐/可选扩大配置分别为29242/27545周期，最大相对误差约6.01e-12，原1e-10容限保持不变。合成4096点、真实路径、短线冷/热轮和有限信用压力分别报告；完整验收及最终二进制复跑证据见报告中的 verification.json。

## 已实现的模型

### 计算访问名额

`--coeff-onchip-compute-reserve=N` 为已经能够执行的操作数读、结果存储保留队列名额。未返回 DMA 的片上写入预约在队列占用达到 `depth-N` 时停止准入。DMA 仍先获得返回接收容量，返回后激活原条目，经真实 bank/端口仲裁后才发布 ready。

默认值 0 保留原路径。它是准入调度选项，不能提高外部存储器吞吐；过大的预留可能压低 DMA 并发。新日志同时记录配置值、预约拒绝次数和未激活条目数。验收重放全部条目的创建、激活、取消和完成，检查保留名额和资源闭合。

### y/Ubar 流式回读

`--coeff-tile-operand-stream=1` 配合 `--coeff-tile-reload=reverse-stream`，将旧的 y-only 回读扩展到同时保存 y/Ubar 的 Tile。y 和 Ubar 各自从高地址回读，并轮转争用相同的 DMA 发包预算。

复用现有 1024 bit 的 Tile ready bitmap：前 `5×cells` 位记录 y，其余 `25×cells` 位记录 Ubar。因此 16、32 点 Tile 可流式处理；超过 bitmap 容量时安全回退到整 Tile 就绪模式，没有新增随线长增长的 bitmap。

一个 cell 的五个 y 字完成 SPM 存储后，可以分配后向操作数槽。每列 Ubar 的五个跨行字都完成存储后，该列才允许发起 SPM 读取；读取完成后才进入算术。两套寄存器槽、Tile 生命周期、DMA 快照和完成栅栏继续保持有界。

在该模式下，`data_wait` 观察的是当前 cell 的 y 是否可读；Ubar 列的数据到达和 SPM 读出仍可造成等待。整 Tile 模式的等待计数与此粒度不同，不能将 `data_wait` 的下降直接解释为全部访存停顿消失。跨模式应同时比较控制器总周期、后向无算术执行周期以及 `CFD_BACK_OPERAND` 的读出/使用时间。

### 输出合并

`--coeff-output-coalesce=1` 使用同一缓存行内连续的输出片段组成最多 64 B 的真实 DMA 写。每个 40 B 结果仍拥有独立的输出槽，直到覆盖它的全部响应返回后释放。

合并包包含最多三个片段，包数据不可变并由响应回调持有。每个 DMA 在途名额新增 128 B 路由/状态预算，加上原有 64 B 数据快照，受 `sizeof(LineOutputPacket)<=192` 检查；该新增预算同时进入 C++、配置和独立容量验收。

凑包等待最多 32 周期。深度 1 队列、队列已满和最后一点直接发送，避免为了等待下一点而形成死锁。独立验收检查逐字节覆盖、物理 DMA 包大小、缓存行边界、片段重叠及最终可见完成顺序。

上述开关可分别关闭，用于同一二进制中的逐项对照；不同规模下应按实测选择组合。

### 一致性 DMA 端点

新增 `--coeff-dma-cache-size`（字节）、`--coeff-dma-cache-mshrs` 和 `--coeff-dma-cache-write-buffers`。默认值仍为 1024、20、8；容量支持 512～65536 B 的二次幂，MSHR 和写回缓冲各支持 1～128。构造 SimObject 时将字节数转换为带 B 单位的字符串，独立验收检查实际 Cache 参数与声明一致。

这些资源属于系统的一致性 DMA 端点，独立于设备 192 KiB 的统一容量预算。扩大端点会增加系统缓存 SRAM、请求跟踪和写回状态，不能将其解释为零硬件成本。端点的 tag/data/response 时序在正式对照中维持各 50 周期；5 周期配置单列为敏感性实验。

## 95% 目标的边界

当前冷轮 4096 点的工作量为 MUL 1453780、ADD/SUB 1249025、DIV 61440。硬件为 5 个 MUL、5 个 ADD/SUB、一个 II=4 的 DIV。

只按算术吞吐计算，下界已经是 `max(1453780/5,1249025/5,61440×4)=290756` 周期。在此下界，加减法器利用率最多 85.92%，除法器最多 84.52%。三类单元同时达到 95% 与当前运算比例不相容。实际还要承担依赖链、数据供给、有限队列和完成过程。

“算术簇活跃比例”表示至少一个操作在执行，并不代表每个通道都有效发射。具体公式及计算结果见 [utilization-bound.json](../../../../results/cfd_dsa/analysis/longline-opt-20261023/utilization-bound.json)。

若下一阶段要求三类单元均达到 95%，资源配比也必须调整。例如 6 MUL、5 ADD/SUB、1 DIV（II=4）的算术下界为 249805 周期，对应理想发射比例约 96.99%、100%、98.38%。这只是工作量上的可行性，尚未实现或仿真；全部达到 95% 要求总周期不超过约 255049，留给数据和依赖气泡的余量很小。还需足够多的独立网格线持续调度，使一条线的后向阶段能与其他线的 LU/RHS 重叠。

## 长线跨轮系数复用评估

当前完整系数缓存要求整线驻留，因此几千点会回退到冷轮路径。本阶段对外存系数 backing 加有限分块缓存完成了容量、流量和运算次数评估；该新跨轮协议尚未实现，不能将估算当成仿真收益。

可行候选为两个各 32 点的 LU/Lbar 缓冲，共 25600 B；Ubar 继续随后向 Tile 回读。按 64 个 DMA 名额、64 项片上队列、输出合并和额外 512 B 标签预算，总预约约为 188672 B，小于 192 KiB。此预算使用原来的 12 个请求状态槽；扩大请求窗口的实验配置需要另行计算。

需要新增冷轮 Lbar backing 发布，以及长度、模式、系数版本、全部 backing 地址匹配的有效性协议。所有系数写回响应完成后才允许跨轮复用；更新、取消、失败和重试均应使对应版本失效。每次使用都须经过 timing DMA 和 bank 端口。

按外存保存原始 LU、warm 每点仍执行五次除法、逐点记录保持不变估算：4096 点单次总逻辑 DMA 从 6217808 B 降到 3760608 B，首轮需额外发布 819000 B 的 Lbar。后续一轮约节约 2457200 B，尚未计量新的控制与预取开销。详见 [external-reuse-evaluation.json](../../../../results/cfd_dsa/analysis/longline-opt-20261023/external-reuse-evaluation.json)。

## 测试解释

真实连通路径、原始编号带状投影和合成规模压力输入继续分别标明。1596 点带状投影包含 21 个互不耦合的 76 点区段，适用于搬运压力评估。原 512 点连通路径的数值失败保留；本阶段没有修改容限，也没有将调度优化解释成数值稳定性修复。

外部存储仍采用 SimpleMemory。降低 DMA cache 延迟的配置属于明确标注的敏感性实验，不作为已经校准的目标硬件参数。扩大 DMA 名额、队列或上下文的配置须单列其容量和结构成本。
