# 单线计算路径优化（2026-10-23）

实现按周期去重的等待归因、把 y 纳入后向有符号归约、冷轮 b 的有界 RHS 归约，以及可测量的共享/LU 专用额外乘法器。推荐继续使用5 MUL＋5 ADD/SUB＋1 DIV、4 bank、192 KiB，保持原算术和一致性端点时序。

推荐入口：[single-line-compute-recommended.json](../../suites/history/single-line-compute-recommended.json)。1024与真实256点开启冷轮b树；4096与65点只优化后向反馈。新增RHS优先级、额外MUL及Tile32保留为实验开关。

反馈从22周期缩到17周期，乘加次数和部分和寄存器数保持原值。浮点结合顺序改变，所有推荐路径使用原有独立数值参考、残差与容限验收。这里没有引入实际FMA，也没有通过缩短算术/内存参数提速。

资源扩充收益小：4096点同一运算图增加一个共享MUL只再省0.20%，Tile16→32则略慢且多占7680 B。当前有效发射率未达95%；4096推荐配置MUL/ADD/DIV为55.54%/47.72%/46.95%。更快的算术反馈暴露了后向数据供给等待，整簇活跃率不等于逐单元有效发射率。

新增观测：

- `CFD_WAIT_CYCLES`：每原因每周期只记一次，可区分当前请求/后台请求；不同原因重叠。
- `CFD_FU_WAIT`：调用方/资源的拒绝发射周期，以及其中当前前向请求的子集；它不是可直接相加的关键路径延迟。
- `CFD_FRONTIER_STATE`：整轮互斥状态分区，包含正在计算的时间。

额外MUL的物理条数、专用通道资格、流水状态预算及利用率分母均显式建模。原全局开关默认关闭，不将实验候选自动推广到所有负载。

最终二进制的22组案例与91项单元测试通过，含边界、inverse、缓存轮次、真实输入和恢复。原有真实连通512点数值失败保留；本次不是完整三维CFD收敛验证。
