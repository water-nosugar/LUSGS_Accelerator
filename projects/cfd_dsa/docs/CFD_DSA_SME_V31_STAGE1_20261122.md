# 阶段 1 技术报告：真实 FP64 时序标定与复用感知去三角化 SME 微架构（V31）

2026-11-22。本报告归档阶段 1（Step 1–Step 6）的完整工程实现、验证结果与架构洞见。在既有 V30 后端（[V30 旁路报告](CFD_DSA_SME_V30_BYPASS_20261119.md)）基础上，本阶段完成两项核心工作：

1. **真实 FP64 流水线时序标定体系（任务 1A）**：补齐 `--coeff-sme-fma-latency` 与三套命名物理时序 Profile（`T0` 历史探索、`T1` 2 GHz ASIC / Arm 核对齐、`T2` UltraScale+ FPGA 预标定），并在 4096 点验证集与留出集上重标定 V14 / V30 与同平台 CPU 基线，**首次定量暴露出真实 FP64 延迟下单线递推反馈墙（17 拍/点与 25 拍/点）导致阵列利用率从 89.35% 骤降至 36.62% / 24.93% 的核心矛盾**。
2. **复用感知双模式去三角化微架构（任务 1B，V31）**：在零新增 ZA Tile 的前提下，引入 **冷轮稀疏 $I_5$ 掩码求逆（70 FMA + 10 MUL）**、**暖轮显式逆 $D^{-1}$ 全 MVM 旁路（`inv-fma1` 5 步满载 5 路 / `inv-fma2` 双链并发）**、**两级硬件条件数门控（11-bit 主元指数差前置过滤 + 导出后 $\ell_\infty$ 指数和复核）逐点安全回退** 与 **显式交叉点自选模式（`Adaptive`）**。

阶段 1 原始 29 项全矩阵实验归档于 `results/cfd_dsa/campaigns/sme-za-v31-stage1-20261122/`、`sme-za-v31-smoke3-20261122/` 与 `sme-za-v31-illcond-v3-20261122/`（冻结构建 `build/cfd_dsa/sme-za/v31-stage1/gem5.opt`，汇总见 [summary.json](/home/zyy/gem5/results/cfd_dsa/analysis/sme-za-v31-stage1-20261122/summary.json)）。代码审查后的修复版本构建于 `build/cfd_dsa/sme-za/v31-stage1-fix/gem5.opt`，已完成单槽位 8 B 标志计费、冷轮缓存写时序门控、等主元病态拦截、`Adaptive` 显式交叉点与回退统计修复及完整回归复核（详见第 2.1、2.2 与 3.1 节）。

## 4. 阶段 1 揭示的核心架构洞见与向阶段 2 / 阶段 3 的精准衔接

本阶段最宝贵的收获不是局部调参，而是通过真实 FP64 时序标定**彻底看清了单线与多线、冷轮与暖轮的真实物理边界**：

1. **揭破 `MUL=1/ADD=1` 假象：真实 FP64 下的“单线递推墙”**：
   * 过去 V30 在 `T0` 下 89.35% 的利用率建立在 `MUL=1, ADD=1`（点间反馈仅 5 拍）的乐观假设上；
   * 换上真实 2 GHz ASIC (`T1`: `MUL=4, ADD=4`) 与 FPGA (`T2`: `MUL=6, ADD=6`) 延迟后，单线前/后扫点间反馈延迟分别锁定在 **17.0 拍/点** 与 **25.0 拍/点**（$4095\times 17\times 2 = 139,230$ 拍，$4095\times 25\times 2 = 204,750$ 拍），`prev_y_late` 高达 **99.98%**，导致单线暖轮利用率分别跌至 **36.62% (`T1`)** 和 **24.93% (`T2`)**；
   * **直接指导阶段 3**：在真实 FP64 延迟下，**单线架构存在物理天花板（17/25 拍/点）**；只有引入 **多线交错 / 块稀疏异步数据流前端（`AW-BDT`）** 同时在阵列中维持 3–4 条独立前沿，才能把 10 路 SME 阵列的真实暖轮利用率从 36.6% / 24.9% 重新拉满至 **90%+**！而一旦进入多线算力受限态（等价于本实验 `T0` 态），V31 `inv-fma1` 的 **99.44% 前向稳态利用率** 与 **−61.5% ZA 读带宽** 将全面兑现为端到端吞吐红利！
2. **明确阶段 2 的两大硬核优化靶点（直接对准 `T1`/`T2` 冷轮瓶颈）**：
   * 在 `T1` (`6R/3W`) 下，冷轮周期为 241k（V30）/ 296k（V31），有效利用率仅 **70.4% / 68.5%**，主要被两件事拖累：
     1. **三角尾块衰减与 6R/3W 写口墙**（冷轮 `write_port` 争用高达 235k–476k 次）；
     2. **`DIV=12~18` 拍主元求倒延迟**暴露在冷轮 LU 关键路径上（`T1` 较 `T0` 满端口冷轮从 179.6k 涨至 208.4k，`T2` 涨至 275.1k）。
   * **这正是阶段 2 两大硬核硬件原语的精确击打目标**：
     * **创新 1（`BD-FMOPA` 块对角分段外积 + 互补阶段配对）**：把缩小中的 `4×4 + 3×3 + 1×1` / `5×5 + 3×3` 打包进单次分段外积，同时压减冷轮 ZA 写次数；
     * **创新 2（对角主元优先发射 + 舍入级直通倒数器 + 自馈三角环）**：在真实 `DIV=12~18` 下将倒数延迟完全隐藏在当前步的非对角尾块更新中，同时把冷轮求逆增量 $\Delta T_{\text{cold}}$ 压低至可接受范围以大幅提前多线交叉点 $K^*$。
